# Диспетчеризація станцій водоочищення

Запуск backend (порт 3000):

    cd backend
    npm install
    npm start

Для розробки: `npm run dev`.

Запуск frontend (порт 5173):

    cd frontend
    npm install
    npm run dev

Збірка frontend: `npm run build`.

Дані зберігаються у backend/data/stations.json та backend/data/modules.json.
